# 浏览器验收记录

2026-09-26，使用 Playwright CLI 驱动 Chromium，验证浏览器原型；不代表 macOS 原生程序性能。

## 已通过的行为检查

- 初始用户目录总计 312.6 GB，40 个示例文件。
- 单击资源库，原位显示更深一级；双击 Developer 进入 38.6 GB 目录。
- DerivedData 加入清单后合计 22.4 GB；模拟移入废纸篓后 Developer 剩余 16.2 GB；撤销恢复 38.6 GB。
- 模拟移入废纸篓时，磁盘可用空间保持 99.4 GB。
- 前进、后退保留导航历史。
- `*.dmg;>5gb` 得到 13.8 GB；`|*.dmg` 得到 294.0 GB。
- 给安装包目录加绿色标记后，`:green` 得到 18.6 GB。
- 无效筛选显示说明；没有匹配项时显示空状态；清除筛选恢复总计。
- 模拟扫描中可以导航；暂停维持状态；继续推进进度；停止明确标记结果不完整；完成后恢复全部示例数据。
- 右键上下文菜单可进入目录。
- 原型说明包含研究边界、资料来源、筛选子集、操作方式和未实现能力。
- 四步引导能进入目录、打开判断依据、加入清单并预览处理。
- 在 1440、1024、768、360、320 像素视口下检查根容器和文档无横向溢出。
- 对桌面、1024 像素宽度、窄窗口、AI 详情和清单截图进行目视检查。窄窗口时文件洞察移到地图下方，长内容通过页面滚动查看。

## 本轮发现并修复

1. 单击已经展开的目录原先不会再显示下一级；现已把额外细节传递到其子项。
2. 状态持久化回传原先会重置前进/后退历史；现已保留同一导航状态的历史。
3. 独立预览的沙箱不允许表单提交，原先 Enter 无法应用筛选；改为明确的按键处理，并增加可点击的筛选入口。
4. 分批模拟处理父子目录时会重复累计废纸篓占用；改为归一化目标，并保存撤销快照。
5. 筛选后的文件洞察占比改用匹配结果计算。
6. 辅助文字最小字号提高至 11px，极小矩形不绘制可能截断的文字。
