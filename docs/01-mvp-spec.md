# MVP 产品规格

状态：Accepted

## 1. 用户问题

用户知道“磁盘快满了”，但不知道空间集中在哪里。系统设置的分类不够细，Finder 逐层查看太慢，传统空间分析器可能扫描慢、界面卡顿或信息噪音过多。

MVP 只解决一件事：**尽快把用户允许访问的目录转换成可持续浏览的面积图，让用户定位最大的目录和文件。**

## 2. 成功路径

1. 启动应用。
2. 选择一个文件夹或磁盘；如果访问受限，应用说明原因和解决方式。
3. 扫描开始后尽快出现第一版空间图，不等待全部结束。
4. 用户单击目录，在当前位置展开更多层；双击进入目录。
5. 用户通过面包屑、后退和上一级返回。
6. 用户悬停或右键查看全名、路径、逻辑大小、已分配大小和可访问状态。
7. 用户可在 Finder 中显示项目。
8. 扫描结束后，界面给出总容量、已用、可用，以及“当前范围 / 卷内其他或未纳入”说明。

## 3. MVP 范围

### 必须有

- macOS 原生应用。
- 用户主动选择扫描根目录。
- 选择 macOS 启动盘时，按 Finder 可见的启动卷组命名空间扫描：跟随系统定义的 firmlink 投影，但把其他真实挂载点作为边界。
- 只读递归扫描；不读取文件内容。
- 目录、普通文件、符号链接、包、挂载点和不可访问项的明确类型。
- 增量结果：扫描过程中空间图可浏览。
- 按已分配大小展示；信息面板同时显示逻辑大小。
- SpaceSniffer 风格的嵌套 treemap。
- 单击展开、双击进入、后退、上一级、面包屑、概览 / 详细。
- 悬停提示、右键菜单、Finder 显示。
- 扫描取消；应用退出时安全停止。
- 快照只作为单会话、单扫描的可再生成缓存；新扫描替换旧扫描，重启后不恢复历史。
- 扫描错误汇总，不因单个目录失败而终止整次扫描。
- 单元测试、集成测试和可重复的性能基准。

### 明确不做

- AI 清理建议、文件语义判断、云端上传。
- 删除、移动到废纸篓、批量清理。
- 重复文件分析、内容哈希、相似图片。
- 实时 FSEvents 增量维护。
- 多磁盘同时扫描、网络磁盘性能优化。
- 精确计算 APFS 克隆文件或快照删除后可释放的字节数。
- Mac App Store 上架流程。

## 4. 交互规则

- 默认打开根节点，空间图占窗口主要区域。
- 面积编码当前视图中每个节点的 `allocatedBytes`。
- 颜色只表示顶层目录归属，不表示安全或清理建议。
- 小到无法显示文字的方块仍保留命中区域；继续缩小时允许合并为“其他”。
- 扫描中的数字带“正在扫描”状态，不能假装是最终值。
- 无权限项在其父目录下保留占位节点并显示错误原因。
- “卷内其他 / 未纳入”是容量对账项，不伪装成真实目录，也不表示垃圾或可释放空间。
- Finder 操作只允许对真实、当前可解析的路径执行。

## 5. 数字口径

- `总容量`：卷总容量。
- `可用`：系统报告的可用于重要用途的容量；若不可用，退化到普通可用容量并标注来源。
- `已用`：总容量减去上述可用容量。
- `逻辑大小`：文件所有 fork 的逻辑字节数。
- `已分配大小`：文件所有 fork 在磁盘上分配的字节数，是空间图默认权重。
- `已归属`：本次扫描成功归入目录树的已分配大小。
- `卷内其他 / 未纳入`：`max(0, 卷已用 - 当前范围已归属)` 的中性展示；普通目录扫描时主要包含选择范围外数据，也可能包含权限、快照、文件系统元数据、克隆共享、其他用户数据和扫描期间变化。
- `与卷用量差异`：当前范围已归属大于卷已用时的诊断差值；不反推独占空间或可释放空间。

界面不得把 `已归属` 与卷 `已用` 强行做成完全相等。

## 6. 安全原则

- MVP 进程不提供写入、删除或清理接口。
- 扫描器只请求枚举与元数据，不打开普通文件内容。
- 日志默认不记录完整个人路径；诊断导出需用户主动操作。
- 取消和异常不得留下后台扫描任务。
- 不跟随符号链接，避免循环和越界访问。
- 启动盘卷组只允许跨越系统 firmlink；不自动跨越外接盘、网络卷、模拟器运行时及其他真实挂载点。
- 应用自己的数据库和临时队列必须显示为叶子边界且不得递归；缓存清理只允许命中严格白名单成员。
- 空间不足时允许保留当前会话中已提交的部分结果，但不得继续写满磁盘或把失败伪装成完成。

## 7. 非功能目标

- 主线程不执行目录枚举、SQLite 写入或大规模布局。
- 扫描开始后 2 秒内出现第一批可浏览结果；慢盘和权限弹窗除外。
- 增量 UI 刷新不超过每秒 10 次。
- 交互期间主线程 p95 帧耗时目标小于 16.7 ms。
- 100 万节点扫描快照的常驻内存目标不超过 250 MB。
- 用户取消后 200 ms 内停止产生新 UI 批次，2 秒内释放扫描资源。
- 任意单个目录错误不会让应用崩溃或丢失已完成结果。

## 8. MVP 完成定义

只有同时满足以下条件才算完成：

- 成功路径在真实 macOS 文件系统上可运行。
- 扫描结果与独立基准工具在定义口径内一致。
- 权限拒绝、符号链接、硬链接、稀疏文件、扫描中变更和取消均有测试。
- 10 万、50 万、100 万节点基准有结果和硬件说明。
- 代表性窗口尺寸下空间图无明显卡顿、重叠或不可达操作。
- 文档、实现、测试和已知限制一致。
