# v0.5.2 · 测试版（未公证）

这是供自愿测试者体验的开源测试版，不是经过 Apple 公证的正式发行版。GitHub Release 标记为 **Pre-release**；版本号为 `v0.5.2`，不加测试后缀。

## 主要功能

- 原生 macOS 磁盘空间图，按占用面积浏览目录和文件。
- 启动页选择扫描范围，扫描结果逐步显示，支持取消、导航和刷新。
- 密集小项目合并显示；磁盘总容量、已用和剩余单独呈现。
- 右键准备 Codex 清理建议草稿，由用户检查并发送，不自动清理。
- 包内原生只读 CLI 提供扫描、状态、目录占用、热点、问题和容量查询；源码另提供可选 MCP 服务。

## 下载与安装

在此 Release 的 **Assets** 中下载文件名以 `.dmg` 结尾的安装包；不要把自动生成的 Source code 压缩包当作安装包。

最低 macOS 14。App 与包内 CLI 均包含 Apple Silicon / Intel 架构。使用 App 和包内 CLI 不需要 Xcode、Swift 或 Node.js；可选 MCP 服务需要 Node.js。

打开 DMG，阅读 `TESTING-README.txt`，再将 SpaceJudge.app 拖入“应用程序”。更新前退出旧版并保留旧应用副本。首次体验建议扫描一个小型测试目录。

本包使用 **ad-hoc 本地签名，不是 Developer ID 签名，未提交 Apple 公证**，下载后可能被 macOS 拦截。仅在确认来源可信时，按 [Apple 的单应用批准说明](https://support.apple.com/102445) 在“系统设置 → 隐私与安全”中处理。不要关闭 Gatekeeper、SIP 或移除隔离属性；受管理的电脑可能不允许安装。

## 安全边界与已知限制

- SpaceJudge 不删除扫描目标，不自动执行清理；扫描会写入自身的本地结果缓存。
- Codex 是外部可选工具，按自身权限运行；任何清理操作需要用户另行确认。
- 占用大小不等于可释放容量；APFS 共享、快照、权限限制和未完成扫描可能影响解释。父子目录不能直接相加。
- 已完成本机构建、签名完整性校验和合成目录 CLI 冒烟测试；尚未完成 Intel 实机、干净电脑真实下载后的 Gatekeeper 安装验收，以及完整外部 Codex 建议流程验收。
- 完整性校验不是安全性保证，也不保证每台 Mac 都能打开。
