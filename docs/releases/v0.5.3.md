## 下载与安装

本版 DMG 下载已撤回。请前往 [v0.5.4 发布页](https://github.com/JoneZhu/SpaceJudge/releases/tag/v0.5.4)下载当前测试版；`Source code` 压缩包不是安装包。下列旧版安装说明仅作历史记录。

1. 打开 DMG，先阅读 `安装与首次打开.html`。
2. 退出旧版，保留旧应用副本；将 SpaceJudge.app 拖入“应用程序”，等待复制完成。
3. 从“应用程序”打开，先选择一个熟悉的小文件夹体验。

最低 **macOS 14**。App 与包内 CLI 包含 Apple Silicon / Intel 双架构；使用它们不需要 Xcode、Swift 或 Node.js。可选 MCP 需要 Node.js，Codex 功能需要另行安装 Codex 桌面应用。

本包使用 **ad-hoc 本地签名，不是 Developer ID 签名，未提交 Apple 公证**，首次打开可能被 macOS 拦截。仅在确认来源可信时，按 [Apple 官方单应用批准说明](https://support.apple.com/zh-cn/102445) 操作。不要关闭 Gatekeeper、SIP 或移除隔离属性；提示损坏／恶意软件时停止强行放行。受管理电脑可能不允许安装。

“仍要打开”与“完全磁盘访问权限”是两种不同的授权；无需为了首次试用就开启完全磁盘访问。

## 安全边界与验收限制

- 不删除或修改扫描目标；扫描只读元数据，会写入自己的本地结果缓存。
- Codex 是可选外部工具，草稿由用户确认发送，清理操作需要另外明确授权。
- 占用不等于可释放容量；父子目录不能相加，APFS 共享、快照及权限限制影响解释。
- 本次通过 596 项 Swift 测试（81 个套件）、146 项发布脚本检查、5 项安装引导检查；MCP 在此前版本通过 49 项测试，本次没有修改 MCP。
- 双架构构建、严格签名完整性、独立 DMG 校验、包内 CLI 合成目录扫描与查询通过；合成文件未被修改。
- 本机预览的欢迎页、无常驻提示及帮助菜单已验收；默认浏览器打开本地帮助的完整流程仍待更多环境验证。
- 尚未完成 Intel 实机、干净电脑真实下载后的 Gatekeeper 安装验收，以及完整外部 Codex 建议流程验收。校验通过不证明软件安全，也不保证每台 Mac 都能打开。
