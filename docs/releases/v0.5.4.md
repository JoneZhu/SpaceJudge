# v0.5.4 · 测试版（未公证）

本版供自愿测试者体验，使用 ad-hoc 本地签名，未提交 Apple 公证，不是 Developer ID 正式发行版。版本号为 v0.5.4，GitHub 使用 Pre-release 状态；保留 v0.5.2、v0.5.3 的原 tag 和安装附件。

## 更新内容

- 增加轻量启动诊断：记录程序入口、缓存准备、数据库连接、模型就绪、界面出现与退出，便于区分系统尚未批准和应用内部初始化问题。
- 应用日志仅包含固定阶段、会话、版本、耗时及允许的数值错误码，不记录扫描名称、路径、结果或错误描述。
- 源码提供只读启动采集工具及[排查流程](../runbooks/startup-diagnostics.md)，用于保存安装身份、签名、隔离属性、进程状态和相关系统日志；不会自动上传或修改系统安全设置。
- 保留独立诊断构建工具，测试副本使用独立身份和缓存；公开包仍使用正常 `SpaceJudge.app`、`com.hongdazhu.SpaceJudge` 和正常缓存，不启用诊断编译条件。

磁盘扫描、空间图、刷新、只读 CLI、可选 MCP 和右键 Codex 草稿能力保持不变，没有增加自动删除或清理。

## 安装

在[发布页 Assets](https://github.com/JoneZhu/SpaceJudge/releases/tag/v0.5.4)选择 `.dmg`，不是 `Source code` 压缩包。公开资产上传与下载校验完成后，此处补充构建记录。

1. 打开 DMG，阅读 `安装与首次打开.html`。
2. 正常退出旧版并保留副本，把 SpaceJudge.app 拖到“应用程序”。
3. 从“应用程序”打开，先用一个熟悉的小文件夹体验。

最低 macOS 14。App 和包内 CLI 包含 Apple Silicon／Intel 双架构；无需 Xcode、Swift 或 Node.js。可选 MCP 需要 Node.js，Codex 功能需要另行安装 Codex 桌面应用。

首次打开可能被 macOS 拦截，仅在确认来源可信时按 [Apple 官方单应用批准说明](https://support.apple.com/zh-cn/102445)处理。“仍要打开”与“完全磁盘访问”不是同一权限。不需要关闭 Gatekeeper、SIP 或移除隔离属性。电脑管理策略可能不允许安装；提示恶意软件或损坏时停止强行放行。

## 首次打开的验收边界

此前本机发生过密码验证完成、系统放行请求被暂存且未及时返回的挂起；原进程停在应用入口之前。完整独立副本和正常身份的重建候选随后都完成了人工下载、安装、单应用批准并显示欢迎页，日志确认系统放行和应用初始化正常。

这不是已确定触发条件并实施永久修复的结论。正常身份候选测试和公开包并非相同字节，本机系统批准历史／共享缓存没有清空；其他 Mac、Intel 实机和最终 GitHub 包的首次批准仍待验证。单元测试、严格签名检查和下载哈希一致不证明软件安全，也不保证每台电脑都能正常打开。

如果批准后无响应，保留现场和安装包，先按启动诊断流程采集；原始系统日志可能含个人路径、下载地址和其他应用授权事件，切勿整个公开上传。应用不会自动连接诊断服务。
