# ADR-0002：空间图默认使用已分配大小

状态：Accepted

## 背景

逻辑文件长度无法反映稀疏文件实际分配；卷已用又包含快照、元数据和不可访问内容。APFS 克隆共享进一步破坏简单相加关系。

## 决策

空间图默认按 `ATTR_FILE_ALLOCSIZE` 布局，同时保存 `ATTR_FILE_TOTALSIZE`。硬链接在一次扫描中只归属一次。卷已用与扫描已归属分别展示；两者差值的产品名称和限制由后续 [ADR-0007](0007-volume-capacity-and-scan-scope.md) 收紧为“卷内其他/未纳入”。

## 后果

- 结果更接近磁盘压力来源。
- 不能承诺删除某节点必然释放相同字节。
- 克隆和快照的精确独占空间留作未来研究功能。
