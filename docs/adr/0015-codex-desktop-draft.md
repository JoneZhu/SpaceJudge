# ADR 0015：右键交给已有 Codex 桌面草稿

日期：2026-10-01。状态：Accepted（0.5.1 本机使用；不批准自动清理或公开发行）。替代 GUI 的 ADR 0014。

0.5.2 的准确路径和 CLI 清理上下文由 [ADR 0016](0016-cleanup-context-cli.md) 扩展；下方旧“不携带路径”指原始 0.5.1 版本，URL 仍不使用 workspace/path 参数。

## 背景与决策

用户要求分析入口放在右键，并直接打开已经使用的 Codex，不再独立登录。
SpaceJudge 从真实项目菜单固定扫描范围，捕获只读、有界、不可变元数据，展示确切草稿供检查，
再通过官方 `codex://new?prompt=...` 预填桌面新对话。只有用户在 Codex 确认发送才发起模型分析。
GUI 不启动 ACP/Node、不嵌入结果，不读写 Codex 凭据或配置。

链接只携带 prompt，不携带扫描原始路径作为工作区，不配置 MCP，不设置自动发送。
保留 CLI/MCP 作为独立的按需查询入口，不宣称已经自动接入。
桌面 Codex 使用自己的权限、工具、登录和记录；此路径不能继承旧 ACP 报告模式的隔离承诺。
草稿要求保守分析，但提示词不是安全沙箱。清理需额外明确授权。

## 权衡和验收

减少安装、登录和对话管理成本，换取用户在外部应用确认发送与权限。
有界摘要会省略项目，必须保留未知、部分捕获、非独占/非可回收、父子重叠说明。
未安装或打开失败时保留可复制草稿；系统接受打开请求不等于接收完整文本或模型完成。
跨桌面版本兼容、实际草稿接收、真实模型效果仍需独立验收。
