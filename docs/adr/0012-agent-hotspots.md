# ADR-0012：用有界最佳优先遍历提供 Agent 全局热点

状态：Accepted

日期：2026-09-28

## 背景

现有 Agent 只能通过 `list_children` 逐层发现大目录。一次整盘分析需要多轮调用，而对全表
按容量排序会增加扫描索引、数据库体积和写入成本。

## 决策

新增只读 `get_hotspots` MCP 工具及对应 Swift CLI 命令。查询从用户提供的 scope 节点
开始，通过现有有界 child-page 查询做最佳优先遍历，返回最多 50 个祖先包含式热点。

- 不新增数据库 schema 或全局 size index；
- 排序使用 effective attributed bytes、相对深度、node ID；
- 结果明确为 ancestor-inclusive，禁止直接求和；
- 仅查询持久化终态；
- 不返回绝对路径，不改变授权与只读边界。

## 后果

正面：Agent 一次调用即可获得跨层热点；查询和内存成本由 limit 严格约束；不影响扫描
写入性能。代价：结果包含祖先/后代重叠，需要调用方按树理解；它不是清理候选或可释放
空间估算。

## 替代方案

- 全表排序：查询直接，但需要大型索引或昂贵临时排序；拒绝。
- 只包装 `list_children`：没有减少多轮 Agent 往返；拒绝。
- 直接输出清理建议：缺少稳定分类与风险证据，超出本阶段安全边界；拒绝。
