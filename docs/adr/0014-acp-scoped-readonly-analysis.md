# ADR 0014：ACP 调用 Agent，MCP 回查固定范围快照

日期：2026-10-01。状态：Superseded（原开发预览范围；GUI 决策由 [ADR 0015](0015-codex-desktop-draft.md) 替代，实验源码保留，不批准开放清理执行）。

## 背景

SpaceJudge 已有原生扫描/SQLite/CLI/MCP。用户希望从空间图发起 Codex 协作，并让 Agent 反向查询 SpaceJudge。若调用旧的 start_scan，会生成另一份结果，可能与 UI 当前扫描不同；若复用用户默认 Codex 工具集，只读 sandbox 并不能约束外部 MCP 的副作用。

## 决策

SpaceJudge 作为 ACP client，经锁定的 codex-acp 适配器建立单轮只读会话。将 UI 已有终态扫描的选中子树导出为有界、带版本的不可变元数据报告，使用既有 MCP SDK 暴露三个查询工具。Agent 不持有原始路径、不触发重扫，也不修改实时 UI 快照。

保留原 CLI 与八工具 MCP 兼容性。报告模式不引入第二套扫描引擎。bytes 与 GB 并列，截断、未捕获页面和部分扫描明确区分，不宣称占用就是可回收空间。

专用 Codex home、明确确认 read-only、禁用 Shell/网页搜索/Apps/图像/浏览器、拒绝客户端权限申请；不继承现有用户 MCP 配置、账号凭据或额外技能。允许锁定 Codex 自己生成的内置 `.system` 资源与空插件目录，否则重复启动会误报。用户自行独立登录。

## 权衡

有界报告牺牲任意深层按需查询和实时性，换取可控上下文、固定版本、范围隔离和不影响扫描的交接。用户可以进入更小的目录重新分析。acpx 需要不同 Node 基线，本版直接连接 ACP 适配器，不另装全局运行时。

开发预览依赖外置 Node/AgentMCP，真实登录后的工具清单与分析效果、进程强杀恢复、runtime 分发及签名仍待验收。模型/适配器不是权限安全边界，不声明具备“只能读报告”的 OS 级沙箱。升级依赖或开放更多能力必须重新审计。

## 非目标

不执行清理、不开放执行命令、不读取文件内容、不自动发送真实用户磁盘数据。不接入 Claude/网页聊天 UI、不管理长期会话、不复制默认 Codex auth 文件。
