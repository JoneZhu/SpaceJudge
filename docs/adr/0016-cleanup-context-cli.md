# ADR 0016 清理上下文和原生 CLI 优先

2026年10月1日，Accepted，本机 0.5.2 使用范围。扩展 ADR 0015 的外部桌面交接，不批准自动清理。

用户需要的是按实际目录给出清理方案，并让 Codex 能继续定向核查。
改为固定目标路径、扫描上下文、清理任务与输出要求，同时提供原生 CLI 用法。
完整路径单独承载于运行时 CodexCleanupContext，可在确认面板关闭，不写 SQLite、不改变旧 path-free ACP 报告。
不通过 workspace URL 参数扩大 Codex 的默认访问；Agent 核查遵守自己的权限，清理仍需单独授权。

原生 CLI 随本机 App 打包、明确签名、双架构校验，优先于必须另行配置的 MCP；既有 CLI/MCP 不变。
CLI 可对所选目录独立扫描、查询热点/容量/问题，结果与 GUI ID 分离，不承诺自动更新 GUI。
工具只读元数据，仅写本任务快照；提示词允许这类核查，但不允许自动删除、prune 或停止服务。

方法、官方参考和验收详见[文档42](../42-cleanup-context-and-cli.md)。
