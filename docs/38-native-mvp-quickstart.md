# SpaceJudge 本机 MVP 使用说明

本说明介绍原生 macOS MVP 的启动与核心操作。应用只读文件元数据，不读取文件内容、不删除，
普通扫描不上传。0.5.2 从右键提供 Codex 清理方案草稿，打开前展示范围、可选准确路径和隐私说明，用户在 Codex 确认发送。
扫描验收与测量口径见 [MVP 验收](37-native-mvp-acceptance.md)，最新分析入口见 [清理上下文与 CLI](42-cleanup-context-and-cli.md)。

状态：本机已安装 0.5.2 构建 7，保留启动页、实时目录占用和保留位置的后台刷新。附带原生 CLI helper，不附带 Node/ACP runtime，也不要求 SpaceJudge 独立登录。
真实模型分析仍待用户确认发送后验收；首次扫描取消后部分结果仍可从真实目录链浏览。
这是本机使用版本，不作公开分发。

## 启动和选择位置

本机安装位于 `/Applications/SpaceJudge.app`，不需要先编译源码。
先退出正在运行的旧版，以免 macOS 把打开请求交给旧实例。双击新版应用，
或在终端执行：

```sh
open /Applications/SpaceJudge.app
```

`output/cleanup-strategy-0.5.2-20261001` 中的 DMG 是保留签名校验的只读备用包。如果文稿云盘给 `.app` 补写 Finder 元数据，
导致副本校验失败，可打开 DMG 后运行其中的 SpaceJudge.app，不要为此关闭系统安全保护。

启动页提供“我的用户目录”“Macintosh HD”“选择其他文件夹”三个入口。快捷位置只是
系统选择窗口的起点，确认位置后才开始扫描；取消选择会留在启动页。没有自动整机扫描，
也不保存最近目录路径。

开始扫描后，窗口立即进入空间图，已知的文件和目录占用分批出现。底部提示结果尚未完整，
顶部显示实际文件数、目录数和处理速率，不显示虚假百分比。大小很小的范围可能很快完成，
应用不会故意拖慢扫描来播放动画。

结果页点击左上角文件夹按钮，或按 `⌘O`，选择其他文件夹或磁盘。在“扫描”菜单里也可以
选择位置。扫描期间可以浏览已发现的目录；刚发现但尚无统计的目录通过顶部项目列表访问。
首次使用建议先选择一个熟悉的小文件夹。没有文件夹授权或完整磁盘访问时，部分位置可能
不可读；应用显示限制，不会自动修改系统权限。

## 看图和操作

- 面积代表已经归属的分配空间；颜色用于区分目录组，不表示清理风险。
- 单击图中的目录会选择并原位展开；双击或选中后 `⌘Return` 进入目录。绿色轮廓表示选择。
- 用返回、上一级或路径面包屑导航；进入子目录后，底部“当前位置”随范围变化。
- 概览和详细切换显示密度；右键提供进入、展开或折叠、信息、在 Finder 中显示、用 Codex 分析。
- 顶部项目列表最多显示当前范围500项，包括不占面积的空目录、空文件和稀疏文件。
- 通过列表选中尚无面积或0占用的目录后，用信息面板中的“进入”访问，不需要在图上找块。
- 信息面板显示名称、相对路径、容量和统计状态；扫描更新后，已选详情会同步变化。
- 首次扫描期间点击取消保留已提交的部分结果。
- 完成或取消后按 `⌘R` 或右上角刷新按钮，后台刷新整个扫描范围；不是只扫当前子目录。
- 刷新期间保留旧图和浏览位置，并提示“当前显示上次结果”。取消或失败不会覆盖旧结果。
- 刷新成功后按真实目录链恢复当前位置；原目录已删除时，回到最近仍存在的上级。
- 下方显示扫描范围的减少量。这不等于磁盘实际可回收量；磁盘剩余空间单独重新读取。
- 再次选择位置时点击取消，不改变原来的结果。关闭应用结束本次访问和扫描。

自动浅层预览不等于全部展开。用户手动折叠的目录不会在下一次刷新时又自动打开；非常小的
项目可能合入“其他”，该块没有虚构文件路径。进入目录或查看有界列表可以继续定位。

## 容量的含义

底部小条的总容量、已用和剩余是所在卷的系统读数，不是当前文件夹的总量。悬停可看来源
和扫描范围对账。系统“重要用途可用”与 `df` 可能口径不同，不能混用计算释放空间。

文件夹大小是扫描已归属的分配字节，硬链接只归属一次，符号链接不跟随；稀疏文件的逻辑
大小可能很大但分配为0。APFS克隆、快照和共享块没有独占空间估算，因此图上的大小不等于
删除后必然可回收的大小。GB使用十进制单位；CLI/MCP另外保留精确字节字符串。

“—”表示未知，不代表0。活动扫描的“正在统计”和取消后“未完成”含义不同；空目录与有项目
但分配为0也有不同提示。扫描中不显示虚假的完成百分比。数据发生变化时，可以重新扫描。

## 本机交付边界

当前 0.5.2 App 与 CLI helper 为 universal arm64/x86_64 的本机 ad-hoc Release。GUI 不打包或启动 Node/ACP，也无需为此安装 Rosetta；实机验收在 Apple Silicon 上进行。
没有Developer ID签名、公证、对外发行或Intel实机验收，不能把这个包当作公开分发版本。
此次按用户要求替换 `/Applications/SpaceJudge.app` 并保留旧版备份；没有改变已安装的 CLI。快照存放在
`~/Library/Caches/SpaceJudge`，应用会排除自己的工作区。GUI 后台刷新期间最多保留两份快照，
用于失败恢复和位置匹配；下一次刷新淘汰无关候选，不会无限积累。CLI 仍默认只保留一次扫描。

此轮实机验证只使用合成夹具，用户Downloads未扫描、未修改。

## 用已有 Codex 分析

扫描结束后，右键图中的真实文件或文件夹 →「用 Codex 分析…」。检查固定范围、大小和摘要，
点击「打开 Codex 草稿」，在 Codex 新对话中再次检查并确认发送。扫描/刷新中、过期场景或合成“其他”块不支持分析。
没有顶栏 AI 按钮、专用登录或 Node 设置；如果桌面 Codex 已登录，使用其自身登录状态。
SpaceJudge 不读取、复制或修改 Codex 凭据、配置。未安装 Codex 或跳转失败时，可复制草稿自行粘贴。

交接含有界名称、可选准确路径、大小、扫描时间与卷容量，以及 SpaceJudge CLI 调用指南。路径在面板中明确显示，可关闭；不含文件内容，不自动发送，不自动接入 MCP。
Codex 的目标是先核查并给出清理步骤、风险和收益，而不是只复述占用。允许必要的只读核查与所选目录定向扫描。
这是外部对话，不是 SpaceJudge 的只读沙箱；Codex 使用自己的工具和权限，清理、prune、停服务等仍需另外授权。
处理后回到 SpaceJudge 按 `⌘R`，刷新整个扫描范围并保留浏览位置。
CLI 定向扫描和查询已用合成夹具实测；自动化不能查看 Codex 自身窗口，草稿接收与真实模型效果待人工确认。详见[清理上下文与 CLI](42-cleanup-context-and-cli.md)。

## CLI 和 Agent 入口

CLI 继续使用上一轮交付的 `spacejudge-agent-cli`，为 Apple Silicon 原生二进制。
此次更新没有替换旧独立 CLI 或全局 MCP 配置，额外随 App 提供无需 PATH 配置的 CLI：

```sh
/Applications/SpaceJudge.app/Contents/Helpers/spacejudge-agent-cli --help
```

新草稿优先告诉 Codex 这个实际位置和定向扫描、热点查询的方法。CLI 创建独立任务快照，ID 不与 GUI 混用，不自动更新 GUI。
可以直接运行查看参数：

```sh
/Users/example/Documents/ChatGPT/SpaceJudge/output/mvp-ready-20261001/spacejudge-agent-cli --help
```

启动图形界面用上面的 `open .../SpaceJudge.app`；CLI用于JSON/NDJSON只读查询，不等同于
图形界面命令。已安装的CLI与全局MCP配置没有自动覆盖。接Agent时显式指定这个新CLI路径，
并按[本地MCP说明](runbooks/local-agent-mcp.md)只授权需要观察的目录；不提供公网MCP。
