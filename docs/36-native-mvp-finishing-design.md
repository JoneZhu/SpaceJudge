# 原生 MVP 界面与关键路径完成设计

状态：Accepted。已实施并完成最终 Release 独立验收，结果见文档37。

本阶段以用户已经确认的简洁原型为视觉与交互基准，完成可以在本机交付的 macOS 应用。
重点不是再增加功能，而是让选择目录、增量扫描、嵌套浏览、导航、取消和错误恢复连成一条
可实际操作的路径。Codex 负责设计与独立验收，Pi 负责原生实现和自测。

## 交付范围

保留 Swift 6、SwiftUI 应用壳、单 AppKit/Core Graphics 画布、Darwin 元数据枚举和 SQLite
快照。CLI 与本地 stdio MCP 继续只读，双单位与既有数据语义不变。第一版仍不加入 AI、
删除、文件内容读取、上传或实时文件系统监听。

本机交付物应包括可启动的 Release App、可复验的本地候选及最短使用说明。没有发布凭据
时，不把 ad-hoc 本地构建声称为已签名公证的公开发行版本。

## 界面与交互

上方只有紧凑导航栏，包含返回、上一级、路径、选择位置、重扫或活动扫描取消、概览与详细。
非扫描状态不保留无意义的灰色取消按钮。根名称与当前范围大小可辨认，长路径可以滚动或
截断，但每一级仍可访问。菜单与工具栏必须使用相同的 enabled 条件。

空间图占主要区域，以柔和目录颜色、清晰字号、细边框、圆角和绿色选中反馈接近原型。
默认至少展示浅层嵌套，单击选中并展开，双击进入，返回和面包屑不丢失路径语义。
信息面板不遮挡顶栏，长名称和相对路径不溢出；Other 不提供虚构路径动作。

磁盘总容量、已用和剩余只占一个小地方。容量来源及范围对账可查看，但不能把选中目录
的已归属大小说成整个卷的已用大小。未知用破折号，扫描中数字明确是暂态，不显示假百分比。

建议默认窗口约 1120 × 760 pt，桌面壳至少适配 736 × 560 pt；纯空间图继续验证 320 px
等极端布局。浅色与深色都必须实际检查，不以提高最小窗口尺寸隐藏布局缺陷。

## 自动浅层预览与性能边界

只读取当前页和最大若干目录的浅层子页，默认最多 6 个预览目录、每页最多 80 项。
用户展开最多 8 组、每页最多 200 项，当前页最多 500 项，绘制最多 2000 个 tile。
这些上限应在实现和测试中直接可见，不在主线程递归加载全树。

预览与用户手动展开分开管理。用户明确折叠后不能在下一次刷新又自动打开；进入新 focus
才重置该 focus 的预览选择。场景、路径和布局异步结果必须与扫描代次、focus 和展开版本
匹配，快速连续导航只应用最后一个结果。

hover、选中或模式切换不触发不必要的数据库读取。拖动窗口采用有界 latest-wins 布局，
不生成无界后台任务；字体、颜色和文字绘制应按实测优化，不创建每 tile 一个 NSView。

## 状态与恢复

需要区分未选择、选择中、扫描准备、首批等待、扫描中、完成、取消后的部分结果、空目录、
仅有零分配大小项目、扫描错误、场景读取失败和启动错误。空白不能直接等同于没有文件，
稀疏或空文件不虚构面积，但必须有说明和访问其信息的轻量入口。

失败保留已提交的结果并提供明确重试；旧图与新 focus 不一致时必须标注加载或保留旧图，
不能靠清除错误文字假装读到了新结果。信息与错误状态不能跨新扫描残留。
权限问题提供解释，不自动授予系统权限。取消后普通 UI 批次停止目标为 200 ms，
worker 结束目标为 2 s；退出时关闭读写连接并停止扫描。

## 容量异常零值修复

此前实际记录出现 Foundation important-usage 返回 0，而 `df` 仍有可用空间，导致扫描
错误被空间门拒绝。本阶段使用同一解析规则供卷事实与快照空间门使用，保留有效的正
important-usage 值；矛盾零值应核对普通容量和 Darwin 文件系统可用容量。

Darwin fallback 为 `f_bavail × f_bsize`，只采样存在的实际路径，乘法溢出和查询失败为未知。
真正全部为 0 的事实保持 0，不降低 512 MiB 开始门与 256 MiB 运行门。
来源标记与现有 SQLite 编码、CLI/MCP JSON 兼容；不把文件系统可用数值当成独占或可释放量。

## 百万节点内存复核与状态生命周期

独立 Release 基准在百万节点上得到 269,729,792 B 的峰值 RSS；另一个无 fixture 生成的
CLI 进程得到 267,534,336 B，仍超过 250,000,000 B 工程门。初步缓冲对照不足以证明
缓冲是主因，不能仅凭减小参数宣称达标。

定位后已实现状态回收：已消费FIFO槽位置nil；目录最终聚合生成独立值并折叠进父目录后，
回收pending-child计数、自身完成标记、完成详情和聚合工作桶。父节点先捕获再回收，根节点
保留最佳已知总量以维持progress和summary；轻量完成集合保留去重防护。持久化聚合不删，
节点、名称、权限失败、硬链接和符号链接语义不变。最终核心独立百万E2E峰值145506304 B，
完整持久化并关闭重开核对，FD差值0，已通过严格250000000 B门。

目录身份在自身枚举完成时发布，聚合仍等待后代，支持扫描中通过有界列表进入未知权重目录。
已选目录随有效scene更新，不重新选择也更新容量；未知不伪装为0，终态未完成不称仍在统计。
详情查询具有独立代次和有界调度，旧查询不能修改新查询的状态。未放宽规模、单位或资源门。

取消时另用包内一次性checkpoint补齐未发布的目录身份与名称，让已提交文件仍可沿真实
父目录链访问。它不携带聚合、不造面积、不改公开事件或SQLite schema，也不在完整扫描
路径保留每节点副本。checkpoint与终态的任何写入错误都标记失败并上抛，不能被并发取消
掩盖。决策和验收见[ADR 0013](adr/0013-cancelled-directory-checkpoint.md)与文档37。

## 启动选择与实时扫描

0.4.0 更新由 Codex 直接完成。启动页取代未选位置时的空工具栏，提供用户目录、磁盘与
其他文件夹入口。所有入口经系统选择窗口确认后扫描；不自动扫描整机、不记录目录历史，
安全作用域仍由 DirectoryAccess 成对管理。选择窗口取消时不产生扫描和授权状态变化。

扫描结果来自真实元数据批次。文件即时入批，目录身份在自身枚举结束后发布。GUI 开启
有限的进行中聚合：用迭代后序遍历，把尚未完成的子树已知贡献加到祖先的临时总量，不修改
最终折叠桶；已完成子树已经折叠，不再次加入。这既避免逐文件沿全部祖先更新，也避免
最终统计重复。未发布目录身份不发布聚合，遵守 SQLite 外键约束。

常规临时聚合最多每 500ms 发布一次，每批最多 512 个目录；优先根及已知占用较大的目录。
首个可见的未完成子目录可以提前发布一次，避免已发现的大目录一直没有面积。无权重的
目录仍是未知而不是伪造的零。终态聚合仍按原规则生成，临时记录不会覆盖完成记录。
CLI 默认关闭此功能，不额外产生 GUI 所需的临时记录。

模型合并进度为 10Hz，地图读数延续 250ms 或展开时 500ms 的单请求节流，后台做布局，
主线程使用单个 AppKit 画布。动态效果由活动指示器和真实批次出图组成，不加入逐块弹跳、
逐块视图或人为扫描延迟。目录颜色按名称的确定性哈希选择，同一目录不会因大小排名或
扫描内 ID 改变而换色；子层仍继承目录组颜色。名称相同或哈希碰撞可共享颜色，颜色不是
唯一文件身份，标签和目录链才是身份依据。

## 保留旧结果的全范围刷新

这轮只实现整个已选扫描范围的后台重扫。进入某个目录并按刷新仍会重扫原根范围；工具栏
与菜单明确写“刷新整个扫描范围”。局部目录刷新需要子树替换、祖先总量合并和不同更新时间
的语义，尚未实现，界面不提供伪装成局部刷新的入口。

刷新期间模型继续展示旧 ScanID、旧空间图、旧卷容量和旧详情；后台新 ScanID 的开始、提交
和终态事件走独立分支，不把新批次接到旧节点。进度显示实际新扫描计数，地图明确标为
上次结果，仍可在旧图中浏览。取消目标是新 ScanID；新扫描尚未开始时取消消费者任务。

SQLite GUI 写库可显式保护当前展示的 ScanID，新扫描开始时只淘汰其他候选，并保留新候选，
最多两份。重复失败或取消不能淘汰仍展示的旧快照。改选其他位置会解除保护，恢复单份
开始语义；CLI 仍默认单份保留。存储空间检查和删除在同一事务，拒绝启动会回滚淘汰操作。
两份快照意味着刷新可能需要额外缓存空间；空间不足时保留旧图并提示，而非偷偷删除旧图。

成功后先从旧快照读取当前焦点与选择项的原始名称字节链，再在新快照用父节点和原始名称
做精确有界查询，每次最多返回一个节点。不能用前 500 项列表匹配，否则小目录会被误判为
已删除。库未实现精确查询时明确报不支持，保留旧图，不做有损猜测。

当前位置在刷新完成时捕获，尊重刷新期间用户的导航。焦点消失时逐层停在最近存续祖先。
新焦点的有界场景预先加载成功后，在主线程不挂起地替换扫描身份、面包屑、场景与容量。
最后替换的短阶段拒绝新的焦点与选择操作，防止读写交叉。读取新场景失败、扫描失败和
取消均恢复旧结果。导航历史重建为新根至当前焦点，原位展开状态重置；不声称完整保留
跨目录历史或全部展开状态。

更新提示只比较两份扫描范围的归属分配字节。它不是独占块回收证明，不据此推算卷剩余。
卷容量来自新终态系统读数，APFS 快照和 Docker 稀疏镜像等情形可能使两者变化不相等。
